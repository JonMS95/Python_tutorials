# Python Mastery Roadmap

This repository contains the material, exercises and projects completed throughout a 30-day Python mastery roadmap.

The goal of the roadmap was not only to learn Python syntax, but also to build a solid engineering-oriented foundation around:

- clean and idiomatic Python
- tooling and testing
- performance and concurrency
- data handling and visualization
- scientific workflows
- C/C++ interoperability
- ML-oriented programming foundations

The repository is organized by topic. Each directory focuses on a specific concept and usually contains commented implementations, experiments or small projects.

Some of the larger projects included are:
- log analysis utilities
- CLI text statistics tools
- C/C++ Python bindings
- plotting and data processing workflows
- a linear regression project integrating Python and C++

Most examples were intentionally written from scratch for learning purposes rather than relying heavily on external frameworks.

The repository also includes Jupyter notebooks used to consolidate concepts and document experiments interactively.
